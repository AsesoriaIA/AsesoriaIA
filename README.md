# AsesoríaIA — Sitio de sustentación

Sitio de sustentación del **Proyecto Aplicado**: *Modelo de asesoría mediado por inteligencia artificial para la planeación docente inclusiva*.

**Maestría en Educación Mediada por las TIC · Universidad Tecnológica de Bolívar**

## 📋 Contenido

- La paradoja de la IA en las aulas (79% vs 30%)
- Contexto: 3 instituciones educativas (Turbaco, Madrid, Itagüí)
- Diagnóstico con 43 maestros
- El modelo de asesoría (sitio web, prompts, GEMA, talleres) con validación experta (97,87%)
- Resultados del piloto: 39 talleres · 44 post-piloto · 14 entrevistas
- Hallazgos, conclusiones y recomendaciones
- Equipo investigador
